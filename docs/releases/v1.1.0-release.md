# 🚀 Release v1.1.0 - The Researcher's Update

## Overview
Release `v1.1.0` is a major feature update that transforms the Gematria Calculator from a simple calculation tool into a powerful research suite. This update introduces the highly anticipated **Custom Cipher Engine** and the **Phrase Comparison View**, alongside critical UX improvements like results sorting, shareable links, and PWA support.

## ✨ Key Features

### 1. Custom Cipher System (Phase 1.1)
- **Create & Manage**: User-defined gematria systems with a full A-Z mapping board.
- **Deep Integration**: Custom ciphers work seamlessly in the main calculator and comparison views.
- **Import/Export**: Share your custom systems with others via JSON files.
- **Preset Generators**: Quickly initialize ciphers with Sequential, Reverse, or Pythagorean patterns.

### 2. Phrase Comparison View (Phase 1.2)
- **Side-by-Side Analysis**: Compare multiple words or phrases in a high-density matrix.
- **Pattern Matching**: Automatically highlights matching values across phrases to reveal hidden patterns.
- **CSV Export**: Export your research data to spreadsheets for further statistical analysis.

### 3. Shareable Links (Phase 2.2)
- **State-Preserving URLs**: Share specific calculation results with pre-populated text and selected systems.
- **One-Click Copy**: New "Share" button with clipboard integration and visual feedback.

### 4. Results Sorting
- **Flexible Ordering**: Sort results by Name, Value (Descending), or your original selection order.
- **Persistence**: Your sorting preference is saved for future sessions.

### 5. PWA Support (Phase 3)
- **App Experience**: "Add to Home Screen" support via `manifest.json`.
- **Standalone Mode**: Use the calculator as a standalone app on mobile devices.

## 🛠️ Technical Improvements
- **Security**: Implemented HTML escaping and robust input validation.
- **Performance**: Optimized calculation loops for large phrase sets.
- **UI/UX**: Refined mobile layout for all new components and added a custom storage monitoring system.
