# Release Notes: v1.2.1 — "The Web & Privacy Pivot"

**Date:** April 13, 2026
**Version:** v1.2.1

## Overview
Version 1.2.1 marks one of the most significant architectural shifts in the project's history. We have transitioned from a static GitHub Pages environment to a robust, PHP-powered cPanel hosting environment, while also hardening the project for private, proprietary research.

## 🚀 Key Architectural Changes
- **PHP 8.4 Migration**: The application core now runs on PHP 8.4, allowing for server-side logic, enhanced security, and modularity.
- **Hosting Migration**: Successfully migrated from GitHub Pages to Apache-based cPanel hosting (`gematria-calculator.jasonbrain.com`).
- **Clean URL Routing**: Implemented `.htaccess` rewriting to enable extension-less URLs (e.g., `/contact` instead of `/contact.php`), improving both UX and SEO.
- **Private Repository Transition**: Reconfigured the project for a private lifecycle, including updated documentation and licensing.

## ✨ New Features & Improvements
- **Native Contact System**: A high-performance, glassmorphic contact form powered by PHP `mail()`.
- **Proprietary License**: Transitioned from MIT to a private repository notice to protect project intellectual property.
- **Design System Standardization**:
    - **Button Components**: Refactored all buttons with a shared base rule, 8px border-radius, and premium hover micro-animations.
    - **Footer Positioning**: Implemented a flex-based sticky footer that remains locked to the bottom on short pages.
    - **Scroll-to-Top**: Centered the floating action button for a more balanced UI.

## 📝 Maintenance
- Established the **Project Maintenance Agent Skill** to standardize future releases and git synchronization.
- Synchronized all legal documentation (`PRIVACY.md`, `TOS.md`) with current hosting and contact info.
