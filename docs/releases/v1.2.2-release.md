## Overview

- **Complete 27-Character Numeral System**:
  - **Units (1–9)**: Alpha (1) through Theta (9) + Digamma / Stigma (`Ϝ`, `ϝ`, `Ϛ`, `ϛ` = 6)
  - **Tens (10–90)**: Iota (10) through Pi (80) + Koppa (`Ϙ`, `ϙ`, `Ϟ`, `ϟ` = 90)
  - **Hundreds (100–900)**: Rho (100) through Omega (800) + Sampi (`Ͳ`, `ͳ`, `Ϡ`, `ϡ` = 900)
- **Comprehensive Sigma Variants**:
  - Full support for standard capital (`Σ`), medial (`σ`), terminal (`ς`), and epigraphic lunate (`Ϲ`, `ϲ`) sigma forms, all evaluating to 200.
- **Polytonic Diacritic Normalization**:
  - Advanced Unicode `NFD` decomposition strips combining accents (acute, grave, circumflex), breathing marks (rough/smooth), diaeresis, and iota subscripts (`[\u0300-\u036f\u1dc0-\u1dff]`).
  - Accurately computes famous theological and historical phrases straight from biblical texts:
    - **Jesus (`Ἰησοῦς`)** = **888** (`10 + 8 + 200 + 70 + 400 + 200`)
    - **Christ (`Χριστός`)** = **1480**
    - **Jesus Christ (`Ἰησοῦς Χριστός`)** = **2368**
    - **The Beast (`χξϛ`)** = **666** (`600 + 60 + 6`)
